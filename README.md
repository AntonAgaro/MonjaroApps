# Monjaro Apps

Android apps for the Geely Monjaro head unit (ECARX, Android 11).

| App | Folder | What it does |
|---|---|---|
| Start Drive Mode ("Режим при старте") | [MonjaroDriveMode](MonjaroDriveMode) | Sets the chosen drive mode (for example Sport) one time after each engine start. |

Each app has its own README with build and install steps.
